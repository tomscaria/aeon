# Cross-Project Lessons

Patterns Aeon has observed across two or more watched repos. Owned by `self-improve`: when the same failure mode appears in ≥2 repos within a 7-day window, append a dated entry here with the pattern, suspected cause, and fix applied (or proposed).

Format:

```
## YYYY-MM-DD — <one-line pattern>
- Repos: owner/repo, owner/repo
- Symptom: ...
- Suspected cause: ...
- Fix: ... (skill name + change, or "proposed — not yet applied")
```

Read by `self-improve`, `skill-evals`, and any skill that wants to avoid repeating a known cross-project mistake. Keep entries terse — this is a signal file, not a journal.
