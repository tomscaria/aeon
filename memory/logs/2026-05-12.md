- **Headline content:**
  - **Core thesis:** agentic LLM systems collapse every task onto natural language as the universal interface, which fundamentally limits applicability to scientific domains where specialized foundation models (predictive, structured, non-linguistic) already exist. Eywa is a **heterogeneous agentic framework** that augments domain-specific foundation models with an LLM-based reasoning interface so the predictive FMs can participate in higher-level planning instead of being bypassed.
  - **Three deployment modes:**
    1. **EywaAgent** — drop-in replacement for a single-agent pipeline; the LLM reasons over the domain FM's outputs.
    2. **EywaMAS** — integrates into existing multi-agent systems by replacing traditional agents with specialized Eywa agents (one per domain FM).
    3. **EywaOrchestra** — planner-based orchestration where a planner dynamically coordinates traditional agents AND Eywa agents to solve complex tasks across heterogeneous data modalities.
  - **Evaluation:** physical, life, and social sciences (specific finance applications not the headline but the architecture is domain-agnostic). Improves performance on structured / domain-specific tasks; reduces reliance on language-based reasoning through effective collaboration with specialized FMs.
