## Confirmed Findings

### Finding 1 — SSRF via Webhook URL (Self-Hosted)

**Severity:** Medium  
**Type:** Code vulnerability  
**CWE:** CWE-918 (Server-Side Request Forgery)  
**File:** `lib/send_webhook_request.rb:24-28`  
**Disclosure channel:** Pending email to `security@docuseal.com` (PVR unavailable)  

The SSRF protection block in `SendWebhookRequest.call` is wrapped in `if Docuseal.multitenant?`. Self-hosted instances (`multitenant? = false`) have no URL restrictions. An authenticated admin can configure a webhook URL pointing to internal infrastructure — cloud IMDS endpoints, private VPC services, Docker bridge. Webhooks fire automatically on any form event. Response bodies are not stored for HTTP 200 responses (blind SSRF), but port scanning and side-effect triggering on internal APIs are viable exploitation paths.

Secondary gap: `DownloadUtils::LOCALHOSTS` (used by URL-based template uploads and the webhook check) does not cover RFC-1918 private ranges or link-local (169.254.0.0/16). The file-upload callers enforce HTTPS via `validate: true`, which blocks cloud metadata services (HTTP-only), but internal HTTPS services on private IPs pass through.

**Advisory draft saved to:** `.pending-disclosure/docusealco-docuseal-2026-05-09.md`

## Dismissed Candidates

- **Open redirect via `completed_redirect_url`** — by-design feature; sanitized via `@braintree/sanitize-url` before `window.location.href` assignment (blocks `javascript:`)
- **CORS misconfiguration** (`Access-Control-Allow-Origin: *` + `Access-Control-Allow-Credentials: true`) — applies only to blob proxy controller; wildcard + credentials is invalid per spec, browsers reject it; no practical impact since API auth uses token header, not cookies
- **Setup controller** — properly guarded by `ensure_first_user_not_created!`; inaccessible after initial setup
- **System calls** — only one `exec()` call in `puma/plugin/redis_server.rb`, uses argv-array form with no user-controlled input; not injectable
- **ZIP extraction** — uses `File.basename(entry.name)` to strip directory components; no zip-slip
- **SQL injection** — ActiveRecord ORM used throughout; no raw query interpolation found
- **PDF processing** — pure-Ruby HexaPDF library; no external process calls; not injectable
